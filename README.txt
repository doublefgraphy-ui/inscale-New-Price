INSCALE NEW PRICE UI v2

수정사항
1. PC 콘텐츠 폭 1120px → 1420px 확대
2. PC 카드/이미지/제품명/가격 크기 확대
3. VIEW DETAILS 상세 팝업 제거
4. 카드에서 Size / Material / Color / Origin 바로 확인
5. MORE IMAGE는 이미지가 2장 이상일 때만 노출
6. INFO LINK는 기존처럼 직접 이동
7. 모바일 헤더 로고를 이미지(inscale-logo.svg) 방식으로 변경
8. 모바일 헤더 82px → 68px로 축소
9. 모바일 탭/검색/카드 여백 및 폰트 크기 재조정
10. 640px 이하 1열, 641~900px 2열, 901~1250px 3열, 그 이상 4열

로고 교체
- 공식 INSCALE 로고 파일을 같은 이름 'inscale-logo.svg'로 교체하면 모바일에 바로 반영됩니다.
- PNG를 쓰려면 index.html의 src="inscale-logo.svg"를 파일명에 맞게 변경하세요.
