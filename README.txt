INSCALE DISPLAY SALE - 4F

업로드 방법
1. 이 폴더 안의 파일과 images 폴더를 새 GitHub 저장소의 최상단(root)에 그대로 업로드합니다.
2. GitHub > Settings > Pages에서
   Source: Deploy from a branch
   Branch: main / (root)
   로 설정합니다.
3. 잠시 후 GitHub Pages 주소에서 확인합니다.
